# Mix in Rust with Java
 This repository contains the code from the ["Mix in Rust with Java" blog](https://tweedegolf.nl/en/blog/147/mix-in-rust-with-java-or-kotlin).

## Branches
- [main](https://github.com/tweedegolf/java-interop/tree/main): Java benchmarks
- [kotlin](https://github.com/tweedegolf/java-interop/tree/kotlin): Kotlin examples
- [uniffi-tryout](https://github.com/tweedegolf/java-interop/tree/uniffi-tryout): Kotlin benchmarks with additional UniFFI Kotlin bindings (which seem slow compared to the other bindings, likely because their using JNA internally)
